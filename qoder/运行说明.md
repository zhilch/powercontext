# 温故 · 复习教练 —— 运行说明

## 一、项目简介

温故是一个"越用越懂你"的复习教练：录入知识点后，它按遗忘曲线挑出今天该复习的，
用大模型出一道简答题，按要点给你的答案打分，并把**掌握度、复习次数、这次暴露的薄弱点**
写进 PowerContext。下次打开（哪怕隔了几天、换了浏览器），它依然知道该先复习哪里。

核心循环：`录入知识点 → 今日复习清单 → 出题 → 作答 → 打分 → 写入记忆 → 重新排程`。

## 二、环境要求

| 项目 | 版本 / 要求 |
| --- | --- |
| Python | 3.11+（Docker 方式是 3.12-slim，无需本机 Python） |
| PowerContext | 1.2.0（`docker compose` 里已内置镜像构建） |
| 模型 | 任一 OpenAI 兼容对话模型；本项目默认 DeepSeek `deepseek-flash` |
| Docker | 24+ 与 Docker Compose v2（推荐）；也可不用 Docker，直接 `uvicorn` 起应用 |
| 资源 | 2 GB 内存、1 GB 磁盘足够（无向量库、无知识库） |

## 三、部署（Docker，推荐）

### 1. 准备配置

```bash
cd qoder
cp .env.example .env
# 编辑 .env，至少填 DEEPSEEK_API_KEY
```

### 2. 先启动记忆服务

```bash
docker compose up -d --build powercontext
curl -fsS http://127.0.0.1:8000/health/live      # 期望返回 200
```

PowerContext 以本地演示配置启动：SQLite 存储、无鉴权、允许非 loopback（见 `powercontext/Dockerfile`
里的 `POWERCONTEXT_SERVER_*`），数据落在命名卷 `powercontext-data`。**仅限本机演示，不要直接暴露公网。**

### 3. 初始化记忆账本

```bash
bash scripts/init_scope.sh
# 输出最后一行：初始化完成。WENGGU_SCOPE_ID=scp_xxxxxxxx
```

脚本会创建一个 scope（幂等键 `wenggu-main`）并写入 3 条示例知识点（高等数学 / 计算机组成 / 英语写作），
方便评审直接体验"复习 → 打分 → 重新排程"的完整流程。

把输出的 `scp_...` 填进 `.env`：

```dotenv
WENGGU_SCOPE_ID=scp_换成你的scope_id
```

### 4. 启动应用

```bash
docker compose up -d app
# 打开 http://localhost:8080
```

健康检查：`curl http://localhost:8080/api/health` 应返回
`{"status":"ok","model":"deepseek-flash","scope":"scp_..."}`。

## 四、部署（不用 Docker）

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

# 另起一个 PowerContext（如果用 PyPI 安装）
pip install "powercontext[cli,server]==1.2.0"
POWERCONTEXT_SERVER_HTTP_HOST=0.0.0.0 \
POWERCONTEXT_SERVER_ACCESS_MODE=disabled \
POWERCONTEXT_SERVER_ALLOW_UNAUTHENTICATED_NON_LOOPBACK=true \
POWERCONTEXT_SERVER_DASHBOARD_ENABLED=false \
powercontext server run

# 初始化账本（默认连 127.0.0.1:8000）
bash scripts/init_scope.sh

# 起应用
export POWERCONTEXT_BASE_URL=http://127.0.0.1:8000
export POWERCONTEXT_SCOPE_ID=scp_xxxx
export DEEPSEEK_API_KEY=sk-xxxx
export DEEPSEEK_MODEL=deepseek-flash
uvicorn app.main:app --host 127.0.0.1 --port 8080
```

## 五、功能与接口

| 页面 / 接口 | 作用 |
| --- | --- |
| `GET /` | 单页界面（今日复习 / 知识点 / 统计 三个标签页） |
| `GET /api/health` | 应用 + 记忆服务 + 模型名、当前 scope |
| `POST /api/kp` | 新增知识点 `{subject, topic, note}` |
| `GET /api/kp` | 全部知识点（按"该复习了"排序） |
| `GET /api/plan?limit=5` | 今日复习清单 |
| `POST /api/quiz` | 针对某个知识点出题 `{id}` |
| `POST /api/grade` | 评分并写回记忆 `{id, question, reference, answer}` |
| `GET /api/stats` | 总量 / 今日到期 / 平均掌握度 / 按学科汇总 |

**记忆格式**：每个知识点是一条 PowerContext Memory，文本形如

```
KP|id=kp_40751ba4|subject=高等数学|topic=泰勒展开的余项形式与适用范围|score=4|reviews=4|last=2026-11-01|note=佩亚诺型泰勒公式要写全|created=2026-11-01|ts=1793520000000
```

读取时按 `ts` 取同一条知识点里最新的一次记录，所以"复习历史"天然可追溯（旧记录不会被删）。

## 六、遗忘曲线规则

| 得分 | 下次复习间隔 |
| --- | --- |
| 5 | 7 天 |
| 4 | 4 天 |
| 3 | 2 天 |
| 2 | 1 天 |
| 1 | 0.5 天 |
| 0 | 0.25 天 |

排序键：`(距离下次复习的天数, 上次得分)`，所以"过期越久 + 分数越低"的排在最前面。

## 七、配置项

| 环境变量 | 必填 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 是 | 模型 API Key，申请地址 <https://platform.deepseek.com/api_keys> |
| `DEEPSEEK_BASE_URL` | 否 | 默认 `https://api.deepseek.com`，换别的 OpenAI 兼容服务时改这里 |
| `DEEPSEEK_MODEL` | 否 | 默认 `deepseek-flash` |
| `POWERCONTEXT_BASE_URL` | 否 | 默认 `http://powercontext:8000`（compose 内）或 `http://127.0.0.1:8000` |
| `WENGGU_SCOPE_ID` | 是 | `init_scope.sh` 输出的 scope_id |
| `POWERCONTEXT_TOKEN` | 否 | PowerContext 开启鉴权时才需要 |

## 八、已知限制

- 单用户、单账本：一个 scope 对应一个人的复习记录；多人使用请为每人建一个 scope 并分别部署应用实例。
- 出题质量依赖模型，题目偶尔偏难；可以把 `DEEPSEEK_MODEL` 换成更强的模型。
- 复习间隔是固定表的简化版遗忘曲线（SM-2 的简化），没有按题目难度动态调整。
- 评分是模型判断，可能存在少量偏差；分数只用来自我追踪，不作为考试成绩。

## 九、排障

| 现象 | 排查 |
| --- | --- |
| `/api/health` 返回 `degraded` | PowerContext 没起来，或 `WENGGU_SCOPE_ID` 填错（检查 `docker compose logs powercontext`） |
| 页面提示"记忆服务异常" | 同上；确认 `curl http://127.0.0.1:8000/health/live` 为 200 |
| 出题/评分报 502 | 模型 Key 无效或余额不足，看应用日志里的上游返回 |
| 知识点列表一直是空的 | 是否执行过 `init_scope.sh`；scope_id 是否与初始化时一致 |
| 同一天复习两次后分数没变 | 正常：分数取最新一次；`ts` 字段保证按最新记录覆盖 |
