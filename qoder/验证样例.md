# 温故 · 复习教练 —— 验证样例

> 前置：按《运行说明.md》完成部署，`init_scope.sh` 已写入 3 条示例知识点。
> 下面三段是本机真实跑出来的输出（2026-11-01，DeepSeek `deepseek-flash`）。

## 样例 1：录入知识点

**操作**：打开 <http://localhost:8080> → 「知识点」标签 → 填

- 学科：`高等数学`
- 知识点：`泰勒展开的余项形式与适用范围`
- 备注：`总把拉格朗日余项和皮亚诺余项的适用条件搞混`

点「加入复习清单」。

**预期**：表格里出现该行，掌握度 `0 / 5`，复习次数 `0`，状态显示「该复习了」。

**技术核对**（证明写进了 PowerContext）：

```bash
curl -s -X POST http://127.0.0.1:8000/v1/memory/entries/list \
  -H 'Content-Type: application/json' -d '{"scope_id":"<你的 scope_id>"}'
```

返回的 `entries[].text` 里应出现 `KP|id=kp_...|subject=高等数学|topic=泰勒展开的余项形式与适用范围|...`。

## 样例 2：弱答案 → 1 分 → 当天就要再来

**操作**：「今日复习」→ 泰勒那条点「开始复习」→ 出题后输入下面这句（故意只说名字）：

```
泰勒展开的余项就是展开式后面的误差项，有拉格朗日余项和皮亚诺余项两种形式。
```

**实际输出**：

- 题目：`写出泰勒公式中拉格朗日余项与佩亚诺余项的表达式，并分别说明成立条件与主要用途。`
- 得分：**1 / 5**
- 点评：只点出两种余项的名称，没写公式、条件与用途
- 记进账本的薄弱点：`泰勒余项只记名称，公式、成立条件与用途均未掌握，需背默对比。`
- 下次复习：**现在就该复习**（0–1 分 → 0.25–0.5 天后再来）

## 样例 3：强答案 → 4 分 → 推到 3.5 天后

**操作**：同一条再点「开始复习」，这次写完整答案：

```
带拉格朗日余项的泰勒公式：f(x)=Σ_{k=0..n} f^{(k)}(x0)(x-x0)^k/k! + f^{(n+1)}(ξ)(x-x0)^{n+1}/(n+1)!，
其中 ξ 介于 x0 与 x 之间。成立条件是 f 在包含 x0 的区间上有 n+1 阶导数。
它给出误差的定量形式，可用于误差估计、近似计算和证明不等式。
皮亚诺余项只写成 o((x-x0)^n)，只要求 f 在 x0 处 n 阶可导，是定性结论，
通常用于求极限、判断无穷小的阶和局部极值，不能用来估计误差。
```

**实际输出**：

- 得分：**4 / 5**
- 点评：拉格朗日余项完整准确，佩亚诺的条件与用途也答到；不足是没显式写出带佩亚诺余项的完整泰勒公式
- 记进账本的薄弱点：`佩亚诺型泰勒公式要写全：多项式部分+o((x-x0)^n)，勿只写余项。`
- 下次复习：**3.5 天后**（4 分 → 4 天间隔）

## 样例 4：跨会话 / 跨重启仍然记得（记忆在 PowerContext，不在应用里）

**操作**：

```bash
docker compose restart app      # 只重启应用，不动 powercontext
```

刷新页面 → 「知识点」里 3 条记录的**掌握度、复习次数、薄弱点都还在**；
`/api/health` 返回的 scope 与重启前一致。

再进一步，把应用容器整个删掉重建：

```bash
docker compose down            # 不删 volume
docker compose up -d app
```

数据仍在 —— 因为记录根本不在应用容器里，而在 PowerContext 的命名卷里。
