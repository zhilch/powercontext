## 样例 1：把一件事写进账本

**输入**：`记住：我叫沈砚，怕水。`

**阿箬的回答**：

> （阿箬提笔，在账本上添了一行）「记下了：我叫沈砚，怕水。」*她把笔搁回去，抬眼看你。*「明日你若还记得，便是你自己记住的；若忘了，我替你记着。」

**账本核对**（`POST /v1/memory/entries/list`，返回 4 条 active 记忆）：

| kind | 内容 |
| --- | --- |
| setting | 客栈规矩：客人喝下忘川水，次日醒来会忘记一切；只有掌柜阿箬的《记忆账本》能留下东西。 |
| npc | 掌柜阿箬：说话克制、带一点江湖气，习惯用酒和旧事试探客人。 |
| rule | 账本上没写过的事，阿箬一律不知道，只会露出陌生的神色，不会编造客人说过的话。 |
| **player** | **我叫沈砚，怕水。** ← 本轮写入 |

## 样例 2：新会话，她还记得（跨会话复用）

**输入**（新建会话）：`掌柜的，我又来了。`

**阿箬的回答**：

> "又来了"……客官这话说得熟络。可我翻着手边这本册子，只寻见"沈砚，怕水"四字。旁的，我一时竟想不起来了——我们从前，可曾在这店里对坐过？先不必急着答，这碗酒你端一端，看它还烫不烫手。你要坐下说，还是先同我讲讲，你这一路是怎么来的？

→ 命中了样例 1 写入的名字与"怕水"，说明记忆在**新会话**中仍被复用。

## 样例 3：账本没写的事，她不自造

**输入**：`我上次托你办的事，办了吗？`

**阿箬的回答**：

> 这位客官……你这话问得我心里发空。我翻遍了手边这本旧账，上头只记着你叫沈砚，旁的竟一个字也没有。托办的事，我此刻是半点也想不起来，不敢胡乱应你。咱们先把话说慢些——你且饮一口温酒，把由头再提一提？

→ 没有任何具体委托内容被编造，只有账本上确实存在的信息。

## 样例 4：记忆服务不可用时的降级

**操作**：`docker stop powercontext`，然后问 `掌柜的，你还记得我吗？`

**阿箬的回答**：

> 这位客官……我们从前可曾见过？我手边这本册子干干净净，翻不出半个旧名字来。忘川水一过喉，前尘都随它去了，你若真来过，怕是也只剩个模糊的影子。先坐吧，柜台上有温好的酒。你是想先喝一碗，还是先说说，你为什么这样问我？

→ `http_search` 节点走 `default-value`（空账本），应用**没有报错、没有崩溃**，表现为"失忆"。

**恢复**：`docker start powercontext` 后再问 `掌柜的，你还记得我吗？`

> 沈砚——账上就这三个字，旁的任你问，我也答不出。怕水这一条，我倒是记着，也不知是哪年哪月你亲口说的。酒温着，你先坐。这回，是先说说你我的旧事，还是先把这碗酒喝了？

→ 记忆服务恢复后立刻重新读到账本。
