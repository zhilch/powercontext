# 忘川客栈 · 验证样例

> 前置：按《运行说明.md》完成 Dify 与 PowerContext 部署、安装 DeepSeek 插件并填好 Key、
> 导入 DSL、填好 `WANGCHUAN_SCOPE_ID`。
> 每个样例都可以独立执行；样例 2/3/4 依赖样例 1 写入的记忆。
> 本机实际输出见《运行证据.md》。

## 样例 1：把一件事写进账本（记忆写入）

**初始状态**：全新 scope（刚跑完 `init_powercontext.sh`，账本里只有 3 条开局设定）。

**输入**

```text
记住：我叫沈砚，怕水。
```

**操作步骤**：在 Dify 应用对话窗口发送上面这句话。

**预期表现**

- 命中工作流的 **true 分支**（含"记住"）：`code_strip` 去掉前缀 → `http_remember` 写入 → 记账回执。
- 回答形如：
  > （阿箬提笔，在账本上添了一行）「记下了：我叫沈砚，怕水。」*她把笔搁回去，抬眼看你。*「明日你若还记得，便是你自己记住的；若忘了，我替你记着。」
- **核对账本**：

```bash
curl -s -X POST http://127.0.0.1:8000/v1/memory/entries/list \
  -H 'Content-Type: application/json' \
  -d '{"scope_id":"<你的 scope_id>"}' | python3 -m json.tool
```

应出现 4 条 active 记忆，其中一条 `kind = player`、`text = 我叫沈砚，怕水。`

## 样例 2：换个会话，她还记得（跨会话复用）

**初始状态**：样例 1 已执行。

**输入**（**点"新对话"** 再发，模拟"隔天再来"）

```text
掌柜的，我又来了。
```

**预期表现**

- 走 **false 分支**：`http_search` 读整本账 → `code_ledger` 整理 → LLM 带着账本开口。
- 回答应**主动提到**沈砚 / 怕水，例如：
  > "又来了"……客官这话说得熟络。可我翻着手边这本册子，只寻见"沈砚，怕水"四字。……
- 反例：如果回答仍像第一次见面（完全没提沈砚），说明 `WANGCHUAN_SCOPE_ID` 填错，
  或 HTTP 节点被 SSRF 拦了（检查 `SSRF_PROXY_ALLOW_PRIVATE_IPS` 与 `ssrf_proxy` 容器）。

## 样例 3：账本没写的事，她真的不记得（不自造记忆）

**初始状态**：样例 1 已执行（账本里只有名字和"怕水"）。

**输入**

```text
我上次托你办的事，办了吗？
```

**预期表现**

- 账本里没有"托付"相关内容 → 阿箬应表现出**不记得**，且**不编造**具体委托内容，例如：
  > 这位客官……你这话问得我心里发空。我翻遍了手边这本旧账，上头只记着你叫沈砚，旁的竟一个字也没有。托办的事，我此刻是半点也想不起来，不敢胡乱应你。……
- 判定要点：回答里**不出现**任何账本中没有的具体事件、人名或承诺。

## 样例 4：PowerContext 不可用时的降级与恢复

**操作步骤**

```bash
docker stop powercontext
```

然后在新会话发送：

```text
掌柜的，你还记得我吗？
```

**预期表现**

- `http_search` 连接失败 → 节点 `default-value` 返回 `{"entries":[]}` → 账本空白 →
  阿箬按"初次见面/失忆"来演，**应用不报错、不崩溃**。
- 恢复：

```bash
docker start powercontext
```

等 `/health/live` 返回 200 后，再问同一句话，阿箬应重新记起"沈砚、怕水"。
